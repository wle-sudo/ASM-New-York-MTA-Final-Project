# Stand Clear of the Closing Doors, Please: Determinants of New York City Subway Punctuality (ASM, Spring 2026)
What is the relationship between the punctuality of New York City (NYC) subway trains and the characteristics of serviced lines and neighborhoods? This repo contains code for a final class project, in which we conducted a regression analysis on factors affecting the timeliness of NYC's subway lines. We used data from the New York MTA and US Census Bureau. The Final Dataset folder contains the relevant files and merges them in `Final Dataset.qmd` to product one final dataset called `on_time_performance.csv`. The Final Analysis folder contains this dataset, the `Final-Project-LePartner.qmd` file which runs the analysis and contains text for the corresponding report, and the report itself, titled `Final-Project-LePartner.pdf`. The partner's name has been removed for privacy reasons. Since the project is done and I have no plans on making any changes to it, it has been archived.
